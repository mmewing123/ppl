# PPL Ground School

Private pilot (airplane) knowledge test trainer and training tracker for KEDU and a Cessna 152.

* 1,698 questions: 778 real FAA knowledge test bank questions, the 61 official FAA sample questions, and 859 original questions mapped to the Private Pilot ACS (FAA-S-ACS-6C), each with an explanation and a reference. Every answer was keyed and then checked blind by a second reviewer.
* 72 lessons, including a Cessna 152 module and KEDU home base pages.
* Timed 60 question practice exams with an ACS code report, spaced review, weak area drills, flashcards.
* FAA-CT-8080-2H testing supplement figures with zoom.
* Training tab: flight log with debriefs, FAR 61.109 progress, costs and projection.

Static site, no build step. Progress is kept in this browser; use "Copy progress code" and "Paste progress code" on the Home screen to move it between devices or to and from the Claude artifact version.

FAA material (questions, ACS, testing supplement) is public domain. Explanations, lessons and original questions are original work. Aircraft numbers come from the Cessna 152 POH; the club airplane's own POH governs.
